# College Voting System

## Setup

1.  Install dependencies for root, client, and server:
    ```bash
    npm run install:all
    ```
    Or manually:
    ```bash
    npm install
    cd client && npm install
    cd ../server && npm install
    ```

## Running the App

To start both client and server:

```bash
npm run dev
```

This will run:
-   Client on http://localhost:5173 (Vite)
-   Server on http://localhost:5000 (Express)
